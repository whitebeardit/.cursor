# Cursor Configuration

This is a comprehensive Cursor IDE configuration repository providing subagents, skills, commands, and rules for software development.

## Structure

- **Agents**: Specialized subagents organized by language (`dotnet/`, `nodejs/`) and shared (`shared/`)
- **Skills**: Reusable knowledge organized by language and shared practices
- **Commands**: Custom commands for development workflows
- **Rules**: Development guidelines and conventions

For detailed documentation, see [README.md](README.md) and [docs/CREATING_ASSETS.md](docs/CREATING_ASSETS.md).
